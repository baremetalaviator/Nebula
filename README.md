# Nebula

Flight-controller firmware for Project Solaris — hand-written bare-metal C for an Arduino Portenta H7, no vendor HAL, no third-party flight stack.

Consumes the [NovaLink](https://github.com/baremetalaviator/NovaLink) protocol as a submodule under `protocol/`.

Part of Project Solaris: [Vanguard](https://github.com/baremetalaviator/Vanguard) (hardware) · [Observa](https://github.com/baremetalaviator/Observa) (ground station) · [NovaLink](https://github.com/baremetalaviator/NovaLink) (protocol)
